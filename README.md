# EDT Favorites

Плагин для **1C:Enterprise Development Tools**, упрощающий работу с деревом объектов конфигурации. 
Добавляет две простые кнопки рядом с вкладкой **Навигатор**: **Отображать только измененные объекты** и **Отображать только объекты из избранного**.
<img width="773" height="545" alt="image" src="https://github.com/user-attachments/assets/37b872f4-717e-44fe-a351-4fe9c46aeb53" />

Рядом с кнопками фильтром располагается подменю, содержащее список измененных/избранных объектов, к которым можно быстро перейти без необходимости включения фильтра.
<img width="655" height="418" alt="image" src="https://github.com/user-attachments/assets/f1d49079-9bf8-4a30-9b86-03d4694c9d1f" />


## Дополнительные возможности

В контекстное меню объекта метаданных добавлены пункты меню открытия Проводника, Git-shell, VSCode в директории, в которой располагается выбранный объект метаданных.

## Установка

1. Откройте в EDT **Справка → Установить новое ПО**.
2. Добавьте репозиторий:

   ```text
   https://pavel-aparin.github.io/edt-favorites/
   ```

3. Выберите **EDT Favorites**, завершите установку и перезапустите EDT.

После установки в панели навигатора появятся кнопки фильтрации изменённых и избранных объектов а также кнопка добавления/удаления текущего объекта в избранное.
